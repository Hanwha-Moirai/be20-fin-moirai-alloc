# Alloc  
Alloc은 메모리를 할당하듯, 프로젝트의 요구사항과 일정에 맞춰 인력을 효율적으로 배치하고 프로젝트의 일정 및 리스크 관리를 보조하는 PM tool

## 🧩 핵심 기능
- 프로젝트 생성 및 기본 정보 관리

- 일정 관리(캘린더/간트/마일스톤 등)
